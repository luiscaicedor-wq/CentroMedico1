# Guion de demostración (3–5 minutos)

**0:00–0:30** Presentar CentroMedico, tecnología Java, Android y SQLite, y explicar el desarrollo individual.

**0:30–1:30** Abrir pacientes; registrar uno con DNI e historia únicos, buscarlo, ver detalle y editarlo.

**1:30–2:30** Agendar cita para el paciente, seleccionar médico, fecha y motivo; verificar que aparece en «Citas registradas» y cambia el contador del panel.

**2:30–3:15** Cerrar y reabrir la aplicación; comprobar que el paciente y la cita permanecen; mostrar eliminación de cita y paciente (atención: borrar paciente elimina sus citas por FK).

**3:15–4:15** Explicar esquema SQLite, relación FK y flujo UI → ViewModel → Repository → DAO; mostrar UML.

**4:15–5:00** Mostrar roles, pantallas complementarias, mapa de evidencias y contribución individual.
